# Demo Script — Living Docs Agent (5 beats)

**Rig:** Paper Desktop open (file "Jonatech Digital — Documents"), chat LEFT, Paper RIGHT.

## Beat 0 — Fresh brain
Clients file is cold (empty). Agent knows only Jonatech Digital employer vault.

## Beat 1 — Paste meeting notes
Paste notes from a client call → agent banks into `2_Clients.md`, asks only for missing fields.

## Beat 2 — Client URL
Share the client's website → `study_client_website` banks a summary (or graceful pending).

## Beat 3 — Upload inspiration
Upload a proposal design you like → `study_inspiration` banks LAYOUT GRAMMAR only (no inspo colors/fonts/logo).

## Beat 4 — Render
Ask for the proposal → structure from inspo × Jonatech brand × banked content → Paper canvas.

## Beat 5 — Comment moat
Drop comment: *logo too small — and add your TIN.*  
Type: *fix my comments* → edits, screenshot-verify, resolve, DECISIONS + LESSONS grow.

## Kill shot
Kill agent → relaunch → second proposal for the **same** client → **zero questions** (brain + clients file survived).

## Pitch close
"Every builder burns an evening formatting proposals. This hands the evening back — and it gets smarter every correction."
